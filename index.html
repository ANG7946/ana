    4 匯出 VOSviewer 專用檔與 SNA 統計報表

    🎯 對接 VOSviewer 操作指引（方案 A）：

    1. 點擊右側綠色按鈕下載 Scopus 專用 CSV 檔（無論原始檔案為 WoS 或 Scopus，系統皆已完美轉譯為 VOSviewer 支援的 Scopus 欄位結構，並附帶 UTF-8 BOM 防亂碼標記）。
    2. 打開桌面版 VOSviewer ➔ 點選 Create ➔ Create a map based on bibliographic data ➔ Read data from bibliographic database files ➔ 選擇 Scopus 分頁匯入該 CSV 檔即可。
