整體評估:

差異係數 (D*) 的意義：

D* 反映測驗結果偏離理想Guttman模式的程度，範圍0-1，數值越小表示越接近理想反應模式。

計算方法 (Sato-Harnisch 公式)：

D* = C / [4 × N × n × P × (1-P) × D_B(M)]
其中 C：偏離數，N：學生數，n：題目數，P：平均答對率，M：高斯整數值，D_B(M)：邊界校正係數
M = G[√(N×n) + 0.5] (G表示高斯整數值，即四捨五入)
D_B(M) = (N + n - 2M) / (N + n)
理想模式判斷：學生i在題目j應答對 ⟺ (j < 學生總得分) 或 (i < 題目總得分)

D* 值的解釋標準：

• 0.0-0.3： 非常高的一致性
• 0.3-0.6： 良好的一致性
• 0.6-0.8： 中等一致性，需要檢視
• 0.8以上： 一致性差，測驗可能有問題

D* 過小或過大可能的問題：

• 測驗設計： 題目過於簡單或困難、缺乏難度層次
• 樣本特性： 學生能力過於同質、樣本規模過小
• 教學效果： 內容過於基礎、缺乏挑戰性
• 測量品質： 可能影響鑑別度和效度

改善建議：

• 檢視題目難度分布，確保有適當的難度梯度
• 評估樣本的代表性和多樣性
• 結合CP值、CS值等其他指標綜合判斷

試題難度與鑑別度分析

題號 難度 (P值) 鑑別度 (D值) 難度解釋 鑑別度解釋
難度 (P值)：答對率，範圍 0-1，越高表示越容易
鑑別度 (D值)：高分組與低分組答對率差異，範圍 -1 到 1，越高表示越能區分能力差異
難度建議：中等 (0.4-0.6) 最理想，容易/困難 (0.2-0.8) 可接受，過易/過難 需調整
鑑別度建議：≥0.3 良好，0.2-0.3 可接受，<0.2 需改進

試題注意係數 (CP)

題號答對百分比CP 值品質評估
CP值 (試題注意係數)：試題偏離理想反應模式的程度
CP標準：0 ≤ 值 < 0.5 可接受範圍，0.5 ≤ 值 < 0.75 嚴重程度，0.75 ≤ 值 非常嚴重
CP值高的可能原因：
• 題目表達不清楚或有歧義
• 題目難度與整體測驗不匹配
• 題目內容超出學習範圍或過於冷僻
• 選項設計有問題（如有明顯錯誤選項）
建議處理方式：
• 檢視高CP值題目的內容和表達方式
• 考慮修改或刪除問題題目
• 分析題目與教學內容的一致性
🟢 答對率 > 50% 且 CP值 < 0.5，適合區別低成就者與其他學生的試題
🟡 答對率 > 50% 且 CP值 ≥ 0.5，試題可能有異質成分，需修正或排除不佳選項
🔵 答對率 ≤ 50% 且 CP值 < 0.5，適合區別高成就者的優質難題
🔴 答對率 ≤ 50% 且 CP值 ≥ 0.5，試題較不理想，可能有登錄錯誤或題意不明

學生注意係數 (CS)

學生編號得分百分比CS 值學生診斷
CS值 (學生注意係數)：學生反應偏離理想模式的程度
CS標準：0 ≤ 值 < 0.5 可接受範圍，0.5 ≤ 值 < 0.75 嚴重程度，0.75 ≤ 值 非常嚴重
CS值高的可能原因：
• 學生可能猜測答案或有不當答題行為
• 學生對某些簡單題目反而答錯
• 學生學習狀況不穩定或有特殊學習需求
• 測驗環境或指導語可能影響學生表現
建議處理方式：
• 進一步了解高CS值學生的學習狀況
• 檢視測驗實施過程是否有問題
• 考慮提供個別化的學習輔導
🟢 學習良好、穩定性高 - 答對率 > 75%，CS < 0.5
🟡 學生可能粗心大意，不夠細心 - 答對率 > 75%，CS ≥ 0.5
🔵 學習尚穩定，需要再用功一點 - 答對率 50-75%，CS < 0.5
🟠 偶爾粗心，準備不充分，需要再努力 - 答對率 50-75%，CS ≥ 0.5
🟣 學力不足，學習不夠充分，需要更加努力 - 答對率 < 50%，CS < 0.5
🔴 學習極不穩定，可能有隨興讀書傾向，對考試缺乏充分準備 - 答對率 < 50%，CS ≥ 0.5
